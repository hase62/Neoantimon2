# v0.3.0 release validation

The owner approved publication of version 0.3.0 after release acceptance checks.
Keep the immutable v0.2.0 tag and assets unchanged. No release step may rewrite
public history or overwrite an existing tag.

## Scope

Version 0.3.0 consolidates readable documentation/cohort examples, localized
VCF validation corrections, four R resource/predictor setup APIs and the editable
scientific workflow overview. All sixteen exports, scientific schema/ID versions
and existing analysis contracts remain intact. There is no multi-sample-column
VCF support, new scientific algorithm or clinical validation.

## Acceptance evidence

- Full source/installed regression counts, R CMD check, clean-library installation,
  literal Quick Start, four cohorts, external example and setup API/help inventory.
- Public VCF supported/rejected denominators, independent import assertions,
  unchanged semantic outputs/IDs and saved-project reopening across versions.
- Fresh representative reference download, verified cache reuse/checksums,
  explicit reference compatibility, clear missing-tool and licensing diagnostics.
- Shared catalog/runtime synchronization and existing Python/shell regression.
- Figure/source/exports, scientific mapping, visual QA and documentation links.
- No private history/files, secrets, developer paths, datasets or run artifacts.

Record exact commits, artifact hashes, commands and results in the timestamped
release report. Source content and the exact published R archive are checked
separately: ordinary R build timestamps may vary. GitHub-generated repository
archives are distinct from the attached R CMD build source archive.

## Publication and independent verification

1. Confirm the approved source, clean tree, unchanged scientific implementation,
   remote main ancestry and absence of the new public tag/release.
2. Build, install and check the exact final archive; retain its SHA256 manifest.
3. Fast-forward public main normally and verify its exact remote commit.
4. Create a new annotated v0.3.0 tag at that commit; never replace existing tags.
5. Publish the release with the validated archive, manifest and concise notes.
6. Independently download assets and verify hashes, clone anonymously, install
   using ref = "v0.3.0", verify version/exports/help and run the installed examples.
7. Recheck public refs, v0.2.0 assets and the separate Converter Registry.

Real licensed predictor execution, actual MHCflurry installation and other
platforms are not established by synthetic tests. The prior production run used
about 91 CPU minutes and 3.64 GB peak RSS; host sleep affected wall time. Retain
verified inputs/artifacts and reopening evidence instead of repeating it without
a concrete reason. This is a performance observation, not an accuracy benchmark
or an automatic release blocker.

The workflow source, exports and scientific mapping are maintained in
[the figure guide](../user/workflow-overview.md). Longitudinal sample graphs
require explicit settings; external export requires a completed project, not
native scores/grades. Missing evidence, zero and evaluated negatives remain distinct.
