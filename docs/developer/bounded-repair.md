# Bounded molecular-condition and annotation repair

This bounded development repair preserves all 22 public APIs and the identity constructors. Origin.phase_status remains a normal/germline-background label. The existing Origin.origin_warning_codes marks CONDITIONAL support; exported peptide provenance.phase_condition carries the complete phase_context and CONDITIONAL/RESOLVED interpretation. T009_DETERMINISTIC is conditional sequence determinism, not proof of all somatic phase.

When explicitly conditional, an Origin cannot establish native molecular eligibility; hard DNA failures remain failures. Candidate aggregation still accepts another eligible Origin, rejects all-ineligible support, and otherwise returns not_evaluated. Vaccine admission consumes that per-Origin support. external_rank still orders measured scores and is not an eligibility policy. Missing legacy metadata is not relabelled.

Stop-loss extension admits only exact explicit-cis somatic, length-preserving substitutions reached by a complete standard nuclear extension. It does not enumerate unknown combinations or add trans events. Complex/germline extension cases remain guarded. Empty Sec positions yield no annotation identifiers; annotated and used exceptions remain separate.

Saved original results are not rewritten. Fresh baseline/patched runs have separate source/run identities.
